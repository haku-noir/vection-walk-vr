# 00. このプロジェクトの実験内容と測定項目

このプロジェクトがどのような実験のためのもので、何を操作し、何を測定するのかをまとめる。
操作方法・実装の詳細は各ドキュメント（[docs/README.md](README.md) の一覧）を参照。

## 研究テーマの全体像

一貫したテーマは **「HMD に提示する視覚情報を操作したとき、人の歩行・身体運動がどう変わるかを測る」** こと。

VR（Meta Quest）では、眼に届く映像を「カメラ → RenderTexture → 画面全体の RawImage」という
パイプラインに通すことで**自由に加工**できる（反転・切替・合成・遅延など）。一方で HMD の
トラッキングにより**頭部の位置・姿勢（6自由度）を高頻度（50Hz）で客観計測**できる。
この「見えの操作」と「行動の計測」の組合せが全実験の共通枠組みである。

```
  操作するもの（独立変数）                 測るもの（従属変数）
  HMD に提示する視覚情報          →       歩行・頭部運動（位置・姿勢の時系列）
  （反転 / 交互提示 / 運動錯視 …）         とその課題成績・誤差指標
```

プロジェクトは3つの実験系で構成される（1 → 2 → 3 の順に発展してきた）。

| 実験系 | 状態 | 視覚操作の内容 |
|---|---|---|
| 1. 視野反転実験 | 前任者から引き継ぎ（完了済み） | 視野の左右・上下・前後反転 |
| 2. 視点追従実験 | 本プロジェクトの中心 | ライブ映像と事前収録映像の交互提示 |
| 3. 4ストローク運動錯視 | 2 の拡張（新規） | 運動錯視による運動信号の加算・逆転 |

## 1. 視野反転実験（前任者のプロジェクト）

### 実験内容

HMD に映る視野を**左右・上下・前後に反転**させた状態（または視野の**運動成分のみ**を
反転させた状態）で、被験者に運動課題を行わせる。
視覚と運動の対応関係（視覚運動随伴性）を人工的に崩したとき、行動がどのように乱れ、
どのように適応していくかを調べるための実験群である。

課題の種類（シーンごと）:

- **直進歩行**（`Walking`）・**8の字歩行**（`8figure`）・**一般歩行**（`WalkingCourse`）
- **タッチ課題**: 周囲に出る球を視野中央に収める／触れる（`AroundSphere`）、
  飛来する球へのタッチ（`SphereLauncher`）、円柱タッチ（`OutdoorReversion`）

### 測定するもの

- **頭部の位置・回転の時系列**（50Hz、CSV）— 歩行軌跡の乱れ・修正の過程
- **課題固有の成績** — タッチの成否・所要時間など（課題スクリプトごとの追加列)
- 解析は Python（軌跡プロット・ANOVA 等、`Assets/ResultData/` 内スクリプト）

> 学術的背景・仮説の詳細は前任者の論文原稿（Overleaf）にあり、本リポジトリには
> 実験装置としての実装と生データ形式のみが引き継がれている（[reversed-vision/](reversed-vision/) 参照）。

## 2. 視点追従実験（本プロジェクトの中心）

### 問い

歩行中の視野に、**自分の動きと一致しない「事前に収録された歩行視点の映像」が
間欠的に差し込まれた**とき、人の歩行はその映像の軌跡へどの程度**引き込まれる（追従する）** か。

視覚から得る自己運動情報（オプティカルフロー、ベクション＝視覚誘導性自己運動感覚）が
歩行制御にどれだけ寄与しているかを、「映像に導かれて歩けるか」という形で
行動レベルで測定する実験である。

### 実験デザイン

1. **収録走**: 実験者（または被験者）が VR 空間内の直線コース（z = 0 → 10 m）を歩行し、
   頭部の位置・回転（6自由度）を 50Hz で CSV に収録する。
2. **実験走**: 被験者が同じコースを歩行する。HMD には
   **ライブ映像**（今の自分の視点）と**収録映像**（収録軌跡どおりに動くゴーストカメラで
   同一環境を再レンダリングした視点）を、**一定周波数 f で交互に切り替えて**提示する。
3. 試行開始時に被験者の立ち位置・向きは収録開始時点へ自動整合されるため、
   **初期誤差ゼロの状態から、時間とともにどれだけ収録軌跡に追従できるか／乖離するか**が測れる。

「映像を録画して再生」するのではなく「軌跡を記録して同一環境を再レンダリング」する方式のため、
**同じ収録軌跡のまま環境条件だけを変えて比較できる**（同一歩行・異なるオプティカルフローの統制）。

### 操作変数（独立変数）

| 変数 | 水準 | ねらい |
|---|---|---|
| **映像の切替周波数 f** | 0.1〜10 Hz（連続可変） | 視覚情報の更新レート・交互提示のリズムが追従に与える影響 |
| **環境オブジェクト密度** | 高密度 / 低密度 / なし | 視覚刺激のオプティカルフロー量（自己運動情報の豊富さ）の操作 |
| **収録映像の再生成分** | 位置+回転 / 位置のみ / 回転のみ | 誘導に効くのは視点の**並進**か**回転**かの切り分け（再生しない成分はライブの頭部を参照） |

### 測定するもの（従属変数）

実験走のあいだ 50Hz で記録（`following_results_*.csv`）:

- **ライブの頭部姿勢**（位置 XYZ・回転 XYZ）— 被験者が実際にどう動いたか
- **提示された収録視点の姿勢**（同6軸。再生成分の条件による置き換え後の値）— 何に追従すべきだったか
- **表示中のソース**（ライブ / 収録のどちらが見えていた瞬間か）

導出する追従度の指標:

| 指標 | 定義 | 意味 |
|---|---|---|
| **errXZ**（主指標） | ライブと収録の水平面内位置誤差 | 歩行としての追従度 |
| err3D | 3次元位置誤差 | 高さ込みの追従度 |
| 姿勢角差（各軸） | ライブと収録の回転差 | 頭部の向きの追従度 |
| 時間的ずれ | ラグ相関・DTW（解析側で算出） | 追従の遅れ・先行 |

これらを **切替周波数 × 環境密度 × 再生成分** の条件間で比較する。

## 3. 4ストローク運動錯視実験（視点追従の拡張）

### 問い

**4ストローク見かけの運動**（4-stroke apparent motion）を使うと、2枚の映像とその
コントラスト反転画像を周期提示するだけで、実際の移動とは独立に
**一方向の運動信号を視野に加算（または逆転）** できる（原理は [viewpoint-following/08_fourstroke.md](viewpoint-following/08_fourstroke.md)）。

この「見かけの運動信号」が歩行時の自己運動知覚・歩行制御に与える影響を調べる。
極性の切り替えにより、同一の映像素材から3条件を作れるのが特徴:

| 極性 | 与える運動信号 | 予期される知覚 |
|---|---|---|
| Enhance | 実運動と**同方向**の信号を加算 | 加速感（動きの増強） |
| Zero | 運動信号なし（反転フリッカーのみ） | 統制条件 |
| Reversal | 実運動と**逆方向**の信号 | 抵抗感・逆行感 |

### 実験の形は2つ

**(a) 自分の過去映像との4ストローク（4ストローク歩行シーン）**

歩行中のライブ映像と、その**数百ミリ秒前の自分の映像**（遅延バッファ）を4ストローク合成して提示する。
「過去の自分 → 今の自分」への変位が運動信号として繰り返し強調されるため、
自分自身の歩行運動が増強／抵抗されて知覚される。
遅延量・変調周波数・極性を操作し、**頭部軌跡（歩行速度・直進性など）への影響**を
収録走と同じ形式（`trajectory_*.csv`）で測定する。

**(b) 視点追従実験への組込み（Follow モードの4ストローク提示）**

実験2の「ライブ⇔収録の矩形波切替」を、同じ2映像の**4ストローク合成**に置き換える。
単純な交互提示に対して、収録映像方向への運動錯視信号が加わったとき
**追従が促進（Enhance）／阻害（Reversal）されるか**を、実験2と同一の指標
（errXZ ほか、`following_results_*.csv`。ファイル名に `_4stEnhance` 等の条件タグ付き）で比較する。

## 測定系の共通仕様

- サンプリング: **50Hz**（FixedUpdate）で頭部（CenterEyeAnchor）のワールド座標を記録
- 座標系: +X=右、+Y=上、**+Z=コース進行方向**（開始 z=0、ゴール z=10m）。
  回転はオイラー角を −180°〜180° に正規化して保存（内部処理は四元数）
- データ形式・保存先・解析スクリプトの詳細:
  視点追従系は [viewpoint-following/07](viewpoint-following/07_viewpoint-following-experiment.md)、
  視野反転系は [reversed-vision/05](reversed-vision/05_data-and-analysis.md)

## 安全上の位置づけ

交互提示・輝度反転はいずれも**周期的なフリッカー刺激**であり、数 Hz〜十数 Hz は
光感受性発作のリスク帯域と重なる。実験条件（周波数範囲）は倫理審査・安全基準と
併せて決定し、どの実験でも即座に停止（視野マスク）できるポーズ機構を維持している。
